# Ecosystem Radar — 2026-11

Baseline snapshot of agentic AI protocols, SDKs, and runtime standards guiding `agents-for-everything` (`afe/v1`).

## Protocol Stack

- **MCP (Model Context Protocol)** — Stewarded under the Linux Foundation's Agentic AI Foundation (AAIF); universal tool & resource interface (`mcp-servers/`).
- **A2A (Agent2Agent)** — Agent Cards & asynchronous peer-to-peer delegation across vendors (`afe export --as a2a`).
- **Agent Skills (`SKILL.md`)** — Progressive-disclosure capability packaging across coding & desktop assistants (`afe export --as skill`).
- **`AGENTS.md`** — Standard repository instructions for coding agents.
- **AG-UI & WebMCP** — Frontend event streaming and site-declared browser tool interfaces.
- **OpenTelemetry GenAI Semantic Conventions** — Standard span attributes (`gen_ai.*`) emitted by `core-python` and `core-typescript`.
