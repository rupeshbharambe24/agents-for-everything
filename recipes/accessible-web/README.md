# Accessible Web Companion (`recipes/accessible-web`)

Voice-guided browser companion combining WCAG checks, screen narration, and hands-free form filling with confirmation read-back before submission.

## Run

```bash
PYTHONPATH=.:packages/core-python/src python3 recipes/accessible-web/app.py
PYTHONPATH=.:packages/core-python/src python3 -m unittest recipes/accessible-web/tests/test_recipe.py
```
