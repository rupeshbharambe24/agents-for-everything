# AGENTS.md — Instructions for AI Coding Agents

Welcome to `agents-for-everything`. If you are an AI coding agent modifying this repository, follow these rules strictly:

## 1. Source of Truth & Standards
- **`BLUEPRINT.md`** defines the overall catalog, design principles, safety tiers (`S0`–`S4`), autonomy levels (`L0`–`L4`), and phase roadmap.
- **`spec/SPEC.md`** and **`spec/*.schema.json`** define the `afe/v1` contract. Never introduce manifest fields outside `spec/agent.schema.json`, `spec/team.schema.json`, `spec/recipe.schema.json`, or `spec/tools.schema.json` without updating the schema and adding an ADR in `docs/adr/`.
- **`agent.yaml` is the source of truth** for every agent. `CATALOG.md` and `registry/` are auto-generated by `scripts/build_catalog.py` — do not edit generated files by hand.

## 2. Agent Design Rules
1. **One agent, one job:** Split multi-purpose workflows into atomic agents plus a composite agent or `teams/` graph.
2. **Typed contracts first:** Always define `schemas/input.schema.json` and `schemas/output.schema.json`, referencing shared types (`afe://types/...`) in `spec/types/` wherever applicable.
3. **Model-agnostic manifests:** Declare required capabilities (`tool_use`, `structured_output`, `vision`, `native_audio`), never hardcode a vendor model ID inside `agent.yaml`.
4. **Vendor adapters stay isolated:** Keep framework-specific code in `packages/adapters/` or `impl/adapters/`. Core implementations in `impl/python/` and `impl/typescript/` must run on `core-python` / `core-typescript`.
5. **Safety & prohibition policy:** Read `SECURITY.md` before touching `S3`/`S4` agents. Never implement CAPTCHA bypassing, consentless voice/face cloning, unconsented scraping, or autonomous unapproved money/legal/medical decisions.

## 3. Required Verification Commands
Before concluding any task, run:
```bash
PYTHONPATH=.:packages/core-python/src:cli/src python3 -m afe_cli validate
PYTHONPATH=.:packages/core-python/src:cli/src python3 -m unittest discover -s packages/core-python/tests
PYTHONPATH=.:packages/core-python/src:cli/src python3 -m unittest discover -s cli/tests
node --test packages/core-typescript/tests/*.test.ts
```
If you modified an agent, also run `afe test <category>/<slug>` and regenerate the catalog if manifests changed:
```bash
python3 scripts/build_catalog.py
```

## 4. Git Commit Hygiene
- Never commit API keys, tokens, credentials, or `.env` files.
- Never add AI co-author trailers (`Co-authored-by:`) unless explicitly instructed otherwise by the repo owner.
