# Framework Adapters

Thin, non-intrusive adapters allowing any `afe/v1` agent folder to be plugged into popular agent frameworks without rewriting the agent's manifest, prompts, schemas, or evals.

| Adapter | Framework | Language |
|---|---|---|
| `langgraph.py` | LangGraph | Python |
| `openai_agents.py` | OpenAI Agents SDK | Python |
| `claude_agent_sdk.py` | Claude Agent SDK | Python |
| `google_adk.py` | Google ADK | Python |
| `ms_agent_framework.py` | Microsoft Agent Framework | Python |
| `crewai.py` | CrewAI | Python |
| `mastra.ts` | Mastra | TypeScript |
