# `agents-for-everything` (`core-python`)

Dependency-light core Python runtime for `afe/v1` agents, teams, MCP tools, safety enforcement, OpenTelemetry GenAI tracing, and portable exporters.

Works out-of-the-box on Python 3.10+ with zero mandatory third-party dependencies (and seamlessly uses `pyyaml` and `jsonschema` when installed via `.[standard]`).
