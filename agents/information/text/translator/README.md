# Translator `text/translator`

beta · P0 · atomic · safety S0 · autonomy L1

## What it does
Translates text cleanly while preserving glossary terms and placeholders.

## When to use / not use
- **Use when:** Multilingual localization and cross-language communication.
- **Do not use when:** Script-only transliteration.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `text/translator` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
