# Rewriter `text/rewriter`

prototype · P0 · atomic · safety S0 · autonomy L1

## What it does
Rewrites drafts into executive, friendly, concise, or plain-language variants.

## When to use / not use
- **Use when:** Adjusting communication style without changing facts.
- **Do not use when:** Fact checking or summarization.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `text/rewriter` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
