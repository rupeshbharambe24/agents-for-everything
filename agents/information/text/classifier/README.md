# Text Classifier `text/classifier`

prototype · P0 · atomic · safety S0 · autonomy L1

## What it does
Categorizes tickets, emails, clauses, or intents into exact predefined labels.

## When to use / not use
- **Use when:** Routing, tagging, or triaging text into finite categories.
- **Do not use when:** Open-ended entity extraction.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `text/classifier` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
