# Proofreader `text/proofreader`

prototype · P0 · atomic · safety S0 · autonomy L1

## What it does
Polishes drafts prior to publication or email sending.

## When to use / not use
- **Use when:** Final polish before sending docs or emails.
- **Do not use when:** Deep structural rewrites.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `text/proofreader` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
