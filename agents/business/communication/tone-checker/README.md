# Tone Checker `communication/tone-checker`

prototype · P2 · atomic · safety S0 · autonomy L1

## What it does
Flags messages that may read as rude, unclear or risky before sending.

## When to use / not use
- **Use when:** You need single-purpose tone checker (draft → issues + rewrite).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S0`) and declared MCP permissions.
3. Runs `communication/tone-checker` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
