# Terms Simplifier `legal/terms-simplifier`

prototype · P1 · atomic · safety S0 · autonomy L1

## What it does
Translates dense terms of service and privacy policies into plain-language risk bullets.

## When to use / not use
- **Use when:** Performing terms simplifier tasks cleanly within typed I/O contracts.
- **Do not use when:** Tasks requiring capabilities outside declared tools or unapproved autonomous high-stakes actions.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `legal/terms-simplifier` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
