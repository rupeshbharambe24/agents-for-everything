# Calendar Optimizer `meetings/calendar-optimizer`

prototype · P2 · atomic · safety S2 · autonomy L2

## What it does
Protects focus time, groups meetings and flags conflicts and overload.

## When to use / not use
- **Use when:** You need single-purpose calendar optimizer (calendar → proposed changes).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S2`) and declared MCP permissions.
3. Runs `meetings/calendar-optimizer` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
