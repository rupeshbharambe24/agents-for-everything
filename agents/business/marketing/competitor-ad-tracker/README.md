# Competitor Ad Tracker `marketing/competitor-ad-tracker`

prototype · P2 · atomic · safety S1 · autonomy L1

## What it does
Tracks competitors' ads and messaging changes in public ad libraries.

## When to use / not use
- **Use when:** You need single-purpose competitor ad tracker (competitors → changes digest).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S1`) and declared MCP permissions.
3. Runs `marketing/competitor-ad-tracker` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
