# Budget Variance Analyst `finance/budget-variance-analyst`

prototype · P2 · atomic · safety S1 · autonomy L1

## What it does
Explains budget versus actual differences.

> **Important Safety Notice:** Accounting/tax workflow assistant; does not provide regulated investment advice and requires human finance sign-off for ledger postings.

## When to use / not use
- **Use when:** You need single-purpose budget variance analyst (budget + actuals → commentary).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S1`) and declared MCP permissions.
3. Runs `finance/budget-variance-analyst` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
