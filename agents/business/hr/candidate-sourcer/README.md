# Candidate Sourcer `hr/candidate-sourcer`

prototype · P2 · composite · safety S1 · autonomy L1

## What it does
Finds candidates from public professional sources and drafts outreach.

> **Important Safety Notice:** HR decision-support assistant only; final hiring, screening, compensation, and promotion decisions must be made by humans.

## When to use / not use
- **Use when:** You need single-purpose candidate sourcer (role → shortlist + drafts).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S1`) and declared MCP permissions.
3. Runs `hr/candidate-sourcer` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
