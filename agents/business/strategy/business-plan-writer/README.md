# Business Plan Writer `strategy/business-plan-writer`

prototype · P2 · composite · safety S0 · autonomy L1

## What it does
Drafts business plans with market, model and financial sections.

## When to use / not use
- **Use when:** You need single-purpose business plan writer (idea + data → plan).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S0`) and declared MCP permissions.
3. Runs `strategy/business-plan-writer` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
