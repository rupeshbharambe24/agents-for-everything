# Preference Profiler `memory/profile-builder`

prototype · P2 · atomic · safety S2 · autonomy L2

## What it does
Builds a user preference profile with visible, editable, consent-based controls.

## When to use / not use
- **Use when:** You need single-purpose preference profiler (interactions → profile).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S2`) and declared MCP permissions.
3. Runs `memory/profile-builder` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)

afe add memory/profile-builder
