# Voice Command Interpreter `voice/voice-command`

prototype · P0 · atomic · safety S1 · autonomy L1

## What it does
Interprets short natural spoken commands against an allowlisted set of application actions.

## When to use / not use
- **Use when:** Hands-free app navigation and action dispatching.
- **Do not use when:** Long multi-field form interviews.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S1) and declared MCP server permissions.
3. Executes `voice/voice-command` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
