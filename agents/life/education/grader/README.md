# Feedback Grader `education/grader`

prototype · P2 · atomic · safety S1 · autonomy L1

## What it does
Rubric-based feedback on essays, answers and code.

## When to use / not use
- **Use when:** You need single-purpose feedback grader (submission + rubric → feedback).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S1`) and declared MCP permissions.
3. Runs `education/grader` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
