# Formal Proof Assistant `science/proof-assistant`

prototype · P2 · composite · safety S0 · autonomy L1

## What it does
Helps write and check formal proofs (Lean).

## When to use / not use
- **Use when:** You need single-purpose formal proof assistant (statement → proof).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S0`) and declared MCP permissions.
3. Runs `science/proof-assistant` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
