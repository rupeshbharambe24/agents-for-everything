# Legislation Tracker `government/legislation-tracker`

prototype · P2 · atomic · safety S1 · autonomy L1

## What it does
Tracks bills and gazette notifications by topic.

## When to use / not use
- **Use when:** You need single-purpose legislation tracker (topics → updates).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S1`) and declared MCP permissions.
3. Runs `government/legislation-tracker` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
