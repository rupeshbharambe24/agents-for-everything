# Cash-flow Lending Analyst `banking/cashflow-lending-analyst`

prototype · P2 · composite · safety S4 · autonomy L2

## What it does
Assesses small-business credit from consented GST, bank and accounting data (e.g. via Account Aggregator).

> **Important Safety Notice:** Financial compliance assistant; high-stakes KYC, AML, lending, fraud, and dispute actions require human officer review and approval.

## When to use / not use
- **Use when:** You need single-purpose cash-flow lending analyst (consented data → assessment).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S4`) and declared MCP permissions.
3. Runs `banking/cashflow-lending-analyst` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.
