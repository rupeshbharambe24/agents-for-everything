# Synthetic Data Generator `data/synthetic-data-generator`

prototype · P2 · atomic · safety S0 · autonomy L1

## What it does
Creates privacy-safe synthetic datasets that keep statistical properties.

## When to use / not use
- **Use when:** You need single-purpose synthetic data generator (schema/sample → synthetic data).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S0`) and declared MCP permissions.
3. Runs `data/synthetic-data-generator` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
