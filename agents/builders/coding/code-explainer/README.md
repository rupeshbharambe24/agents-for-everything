# Code Explainer `coding/code-explainer`

prototype · P1 · atomic · safety S0 · autonomy L1

## What it does
Explains source files line-by-line or at system-architecture level for newcomers.

## When to use / not use
- **Use when:** Performing code explainer tasks cleanly within typed I/O contracts.
- **Do not use when:** Tasks requiring capabilities outside declared tools or unapproved autonomous high-stakes actions.

## How it works
1. Validates input payload against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (S0) and declared MCP server permissions.
3. Executes `coding/code-explainer` task logic (deterministic local processing or live model execution).
4. Validates output against `schemas/output.schema.json`.
