# Booking Assistant `browser/booking-agent`

prototype · P2 · composite · safety S3 · autonomy L2

## What it does
Finds availability and prepares bookings (tables, appointments, tickets); the user confirms.

## When to use / not use
- **Use when:** You need single-purpose booking assistant (request → options + prepared booking).
- **Do not use when:** Actions exceed declared MCP tools or bypass required human sign-off.

## How it works
1. Validates input against `schemas/input.schema.json`.
2. Enforces `SafetyPolicy` (`S3`) and declared MCP permissions.
3. Runs `browser/booking-agent` logic locally (`mock` or `ollama`) or via any configured model provider.
4. Validates output against `schemas/output.schema.json`.

## Input & Output
- Input schema: [`schemas/input.schema.json`](schemas/input.schema.json)
- Output schema: [`schemas/output.schema.json`](schemas/output.schema.json)
